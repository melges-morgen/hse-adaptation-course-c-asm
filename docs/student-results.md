# Хранение ведомостей и отчётов

В корне репозитория есть локальная папка `results/` для учёта успеваемости.
В ней хранятся только исходные ведомости, обработанные ведомости и отчёты;
работы студентов сюда не складываются.

## Структура

```text
results/
  2026-spring/                 # календарный год и семестр
    БПИ264/                    # группа
      КР-1/                    # контроль
        source/                # исходные ведомости и данные для обработки
        reports/               # обработанные ведомости, отчёты и сводки
      ЛБ-4/
        source/
        reports/
```

Для каждого нового семестра используйте имя `YYYY-spring` или `YYYY-autumn`,
где `YYYY` — календарный год проведения семестра. Внутри создайте папку группы,
затем папку контроля с понятным названием и две папки: `source/` и `reports/`.
Например, исходную таблицу КР1 группы БПИ264 в весеннем семестре 2026 года
поместите в `results/2026-spring/БПИ264/КР-1/source/`, а итоговую ведомость —
в соседнюю `reports/`. Можно использовать ODS, XLS, CSV, PDF, HTML и другие
форматы исходных ведомостей и отчётов.

Весь `results/` исключён из Git через корневой `.gitignore`, включая вложенные
файлы с ФИО и оценками. При переносе репозитория на другую машину данные из
`results/` нужно копировать отдельно. Шаблоны контролей и общие генераторы
хранятся в `assessments/` и `scripts/`; существующие `groups/` и `dist/`
автоматически не переносятся в это хранилище.
