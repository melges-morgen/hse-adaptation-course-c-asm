# Лекция №5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Подготовить полный комплект лекции №5 об истории операционных систем и пути запуска программы: конспект, Reveal.js/PDF, воспроизводимую C-демонстрацию и публикацию.

**Architecture:** Канонический текст размещается в `tex/lectures/`, а `slides/lecture05/index.html` служит редактируемым источником презентации. Одна Linux C-программа иллюстрирует права доступа, аргументы, окружение, стандартные потоки и код завершения; её проверка выполняется в Docker. Существующая инфраструктура Reveal.js, публикации материалов, PDF и GitHub Pages расширяется по шаблону лекции №4.

**Tech Stack:** LaTeX/latexmk в Docker, Reveal.js, Node.js/Playwright slide builder, C11/GCC в Docker, Makefile, GitHub Actions.

## Global Constraints

- Русский язык и требования ПУД из `pud_adaptation_course.tex` являются источником содержания.
- Лекция рассчитана на 90 минут; исторический блок занимает около 18 минут и не выдаёт z/OS за предшественника Unix.
- HTML — редактируемый источник слайдов; PDF создаётся из того же источника в формате 16:9 с заметками преподавателя.
- Студенческий комплект плоский, одинаковый для HTML и PDF, включает README и не содержит преподавательских решений или собранных файлов.
- LaTeX и слайды собираются через Docker; генерируемые PDF не коммитятся.
- Сохранить незакоммиченные пользовательские файлы; не добавлять и не коммитить их.
