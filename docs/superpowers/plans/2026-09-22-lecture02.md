# Lecture 02 Implementation Plan

> Execution: use executing-plans, in this session, with the approved design.

**Goal:** Подготовить занятие №2 на 90+90 минут и три артефакта лекции.

**Architecture:** LaTeX-пособие использует тематические включаемые фрагменты.
HTML Reveal.js использует общую тему и локальные зависимости; Docker-сборка
копирует их в автономный комплект и экспортирует тот же HTML в PDF.

**Tech Stack:** LaTeX/latexmk, Reveal.js 5.2.1, Playwright 1.58.2, Docker, Node.js.

## Global Constraints

- Русский язык, начинающие студенты ПИ, связь с C и NASM.
- Лекция 90 минут; семинар 90 минут; весь тематический охват PPTX.
- Формат 16:9, #1A1B2F, #00D4AA, локальный Carlito.
- LaTeX собирается только внутри Docker через `make pdf`.
- Не коммитить генерируемые PDF и не перезаписывать пользовательскую работу.
