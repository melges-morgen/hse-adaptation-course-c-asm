# Лекция №4: простой компьютер в 16-битном real mode

Решение пользователя: NASM — единственный исполняемый код учебного журнала;
C остаётся способом объяснять алгоритмы. Вместо прежней x86-64 реализации
используется QEMU PC с BIOS, 16 MiB RAM, виртуальной дискетой с программой,
VGA, PS/2, PIC, COM1 и отдельным IDE-диском с оценками.

Маршрут: BIOS → 512-байтовый загрузочный сектор → чтение 17 секторов в RAM
→ переход `1000:0000`. GRUB, ELF, PAE, страничные таблицы и long mode отсутствуют.
Версия 1 выводит запись через BIOS INT 10h; версия 2 хранит 16×4 однобайтовых
оценок и пишет в VGA; версия 3 получает клавиши через BIOS INT 16h;
версия 4 заменяет BIOS-обработчик клавиатуры на IRQ1 + очередь; версия 5
считает среднее в целых сотых; версия 6 читает и пишет сектор HDD через
BIOS INT 13h Extensions. Вызов INT и внешний IRQ обязательно различаются.

Новый сектор имеет сигнатуру `GR16`, версию, размеры, 64 оценки и простую
16-битную сумму первых 72 байтов. Проверка всех полей предшествует замене
рабочей таблицы. DMA, GPU/VRAM, современные интерфейсы и кэш объясняются
как модель или сравнение и не объявляются свойствами 16-битного QEMU.

Архив x86-64 исходников/слайдов/пособия сохранён в `legacy/`. Презентация
Reveal.js и PDF экспортируются из одного HTML в общем стиле; handbook
подключает новый фрагмент. Проверки: сборка 6 образов, QEMU ввод/IRQ,
средние, сохранение/перезапуск, ошибки диска/формата, PDF пособия и слайдов,
визуальный просмотр браузера и PDF. Никакие generated PDF/ISO/RAW не коммитятся.
