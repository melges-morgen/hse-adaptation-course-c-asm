# Ведомость защиты ЛБ4

Создать одну локальную таблицу LibreOffice Calc в формате ODS в `results/2026-autumn/` по 26 уже отобранным отчётам ЛБ4 из `results/2026-autumn/*/ЛБ-4/source/`. Данные студентов не записывать в отслеживаемые Git файлы.

Одна строка на студента; столбцы: «Студент», «Группа», «Работа» (QEMU или Factorial), «Дата получения файла», «Оценка за защиту». Последняя ячейка каждой строки пустая. Сортировка — по группе и фамилии. ФИО брать из отчёта и сверять с локальным `groups/students.csv`; группу без доказательств не назначать. Если название файла и указанная внутри тема работы расходятся, использовать содержание отчёта и отметить расхождение в локальной ведомости.

Время файла в `source/` сохранено при копировании из Telegram Desktop; выводить локальную календарную дату изменения файла (`ДД.ММ.ГГГГ`), подписанную как дата получения **по метаданным файла**, а не подтверждённая дата сообщения. На отдельном листе указать эти ограничения и список трёх требующих проверки документов (без группы, «ЛР1», «ЛР 2»). Использовать редактируемые ячейки ODS с видимыми границами и повторяемой строкой заголовка; не добавлять выставленные оценки.

Проверить, что ODS валиден как ZIP/ODF, основной лист имеет 26 строк данных, оценки пусты, даты совпадают с mtime файлов, варианты соответствуют тексту работ, а документ остаётся внутри игнорируемой Git папки.
