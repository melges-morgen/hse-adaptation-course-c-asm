# Лекция №3. Арифметика с плавающей точкой и погрешности

## Согласованное решение

Подготовить только лекцию: развёрнутый текст пособия, Reveal.js и PDF
из того же HTML-исходника. Пользователь согласовал сбалансированный подход,
90 минут основного материала, дополнительные слайды, структуру и проверки
и дал команду приступить к реализации.

## Маршрут

| Минуты | Содержание |
|---|---|
| 0–5 | Мотивация: `0.1 + 0.2` в binary64 |
| 5–15 | Повторение формата, точность, шаг, normal/subnormal |
| 15–35 | Сложение, выравнивание, guard/round/sticky, округление |
| 35–50 | Вычитание, нормализация, ошибки исходных данных |
| 50–62 | Умножение и деление |
| 62–78 | Поглощение, неассоциативность, границы диапазона |
| 78–87 | Абсолютная/относительная ошибка и выбор допуска |
| 87–90 | Итоги и проверка понимания |

Основная идея: операция даёт округление точного результата над уже
представленными операндами; ошибки представления и вычисления различаются.
Учебная точность явно отделяется от binary32. Режим по умолчанию —
round to nearest, ties to even. Вычитание близких представимых чисел
может быть точным, хотя ошибки исходных приближений усиливаются.

## Материалы и интеграция

- `tex/lectures/lecture03_intro.tex`: цели, время, модель арифметики, справка.
- `tex/lectures/lecture03_arithmetic.tex`: операции, ошибки, C, допуски,
  дополнительные разборы и самопроверка.
- Существующий раздел лекции №3 в `tex/chapters/chapter1_math_foundations.tex`
  заменяется подключениями этих фрагментов. Точка входа остаётся
  `adaptation_course.tex`, метка `lecture03` сохраняется.
- `slides/lecture03/index.html`: самостоятельный сценарий и заметки.
- Общие `slides/theme/course.css` и `course.js`, формат 16:9, Carlito,
  тёмные блоки, бирюзовые акценты, моноширинные машинные представления.
- `slides/presentations.json`, цели Makefile, инструкция README и программа
  отражают новый комплект. Экспортёр и проверка используются общие.
- Семинар №3 и лекция №2 остаются за пределами задачи.

Существующий раздел уже содержит примеры 6.5 + 0.75, округления 1.140625,
1.125 − 1, 1.5 × 2.5, 3 / 1.5 и 1 / 3: их сохраняем и проверяем.
Длинное повторное кодирование −12.625 заменяется ссылкой на лекцию №2.

## Критерии готовности

1. Все числовые результаты проверены точными дробями / IEEE-представлениями.
2. Примеры C имеют явные условия выполнения: binary32/binary64,
   округление к ближайшему, без fast-math и переассоциации.
3. `make pdf` успешно собирает пособие в Docker; проверены ссылки,
   оглавление, кириллица, формулы и предупреждения изменённого раздела.
4. Docker-сборка слайдов проверяет локальные ресурсы, заметки, безопасную
   область, число основных/дополнительных слайдов и страниц PDF.
5. Визуально проверены HTML и страницы PDF, включая двоичные раскладки и код.
6. PDF полезен без интерактивности: важные шаги видны, дополнительные
   слайды помечены. Генерируемые артефакты не добавляются в Git.

Студент может проследить сложение и вычитание, объяснить округление,
поглощение, неассоциативность и выбрать допуски по смыслу задачи.
