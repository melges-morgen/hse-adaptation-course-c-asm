# Лекция и семинар №2: согласованное решение

Пользователь подтвердил полный охват исходной презентации
`Лекция_2_Кодирование_данных_и_команд.pptx` и продолжительность
90 минут для лекции и 90 минут для семинара.

## Артефакты

1. Развёрнутая лекция и семинар в `build/adaptation_course.pdf`.
2. Автономная Reveal.js-презентация `build/slides/lecture02/index.html`.
3. Её экспорт `build/lecture02-slides.pdf`: один слайд на страницу,
   одинаковое содержание и оформление, все фрагменты раскрыты.

Пособие имеет собственный LaTeX-текст, две версии слайдов используют один
HTML-исходник. Общая тема пригодна для следующих лекций. Формат 16:9,
фон #1A1B2F, акцент #00D4AA, светлый текст, Calibri-совместимый Carlito,
терминальный и двоичный декор исходного PPTX. Зависимости локальные.
После визуальной проверки рендера PPTX уточнён обычный макет: светлая
внешняя рамка #F0F4F8 с тёмными округлыми блоками; тёмный фон всей страницы
и точечный декор используются на титульных слайдах.

## Содержание и время

Лекция: введение 5; графика 10; звук 6; текст 9; целые числа 25;
IEEE 754 и точность 20; команды, маски и сдвиги 10; итоги 5 минут.
Подробная арифметика float — дополнительный блок с явной маркировкой.
Лекция №3 становится углублённым продолжением по арифметике и погрешностям.

Семинар: входные вопросы 5; графика и звук 15; текст 10; целые и флаги 25;
float32 15; маски, сдвиги и учебная команда 15; самопроверка 5 минут.
Условия и решения обязательных задач разделены. Существующие разобранные
задачи сохраняются как дополнительный практикум.

## Проверка

Все сборки выполняются в Docker. Проверяются числовые примеры, ASCII/Unicode,
границы IEEE 754, округление, CF для ADD/SUB, машинные сдвиги и отличие от C.
Проверяются LaTeX, оглавление, ссылки, кириллица, переполнения блоков слайдов,
автономность HTML, совпадение числа страниц PDF и числа слайдов,
характерные макеты относительно PPTX. Генерируемые файлы исключены из Git.

## Границы изменений

Обновляются программа, описание практикума, README и сборка GitHub Actions.
Пользовательские изменения Makefile и исходный PPTX сохраняются.
Коммиты и публикация из текущей сессии не запрошены.
