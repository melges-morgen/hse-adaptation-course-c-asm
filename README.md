# Адаптационный курс к дисциплине «Алгоритмы и алгоритмические языки»

Репозиторий содержит методические материалы адаптационного курса для студентов первого курса факультета Программной инженерии НИУ ВШЭ.

Курс предназначен для выравнивания стартовой подготовки вчерашних школьников перед изучением дисциплины «Алгоритмы и алгоритмические языки», в которой используются язык C и ассемблер NASM.

## Содержание курса

Материалы охватывают:

- системы счисления;
- представление целых и вещественных чисел в памяти компьютера;
- базовые понятия архитектуры ЭВМ;
- основы операционных систем;
- Linux как рабочую среду программиста;
- инструменты сборки программ на C и NASM;
- основы Git;
- приложения со справочными материалами.

### Источники истины

Для подготовки новых занятий используйте `pud_adaptation_course.tex` как
актуальную программу раздела 2: именно там зафиксированы темы и результаты
обучения лекций и семинаров №4--8. Текст пособия берётся из
`adaptation_course.tex` и подключённых файлов под `tex/`, а редактируемым
источником презентации является `slides/lectureNN/index.html`.

`docs/superpowers/` хранит историю согласованных решений и планов. Каталог
`legacy/` предназначен только для исторической сверки и не является источником
текущего содержания. Каталог `examples/` содержит внешние образцы и не задаёт
требования курса.

## Сборка PDF

Локальная сборка выполняется только в Docker-контейнере. Устанавливать TeX Live или другое тяжёлое TeX-окружение в систему не требуется.

Для сборки PDF:

```bash
make pdf
```

Результат появится в каталоге:

```text
build/adaptation_course.pdf
```

### Практикум к первой контрольной

`test1_practice.tex` — отдельное пособие по лекциям и семинарам №1–3
(системы счисления, целые числа и числа с плавающей точкой). Оно включает:

- ссылки на основной материал лекций и семинаров №1–3 и необходимые обозначения;
- раздел «Примеры решений» с 10 пошаговыми разборами по занятиям №1–2;
- 32 самостоятельных задания по занятиям №1–2 в восьми тематических блоках;
- два тренировочных варианта: К1–К8 по занятиям №1–2 и В1–В8 по занятиям №1–3;
- краткие ответы, подробные решения, схемы самопроверки на 100 баллов
  и рекомендации по повторению.

Каждый вариант рассчитан на 90 минут (80 минут на решение и 10 на проверку)
и выполняется вручную без калькулятора. В варианте В1–В8 за темы занятий №1–2
предусмотрено 60 баллов, за `float32`, IEEE 754 и округление из занятия №3 — 40 баллов.

Разделы пособия находятся в `tex/practice/test1/` и используют общую преамбулу курса.
В PDF условия, ответы и решения связаны ссылками.
Теория изложена в основном пособии `adaptation_course.pdf`. Ссылки на него в практикуме
относительные: при передаче материалов размещайте оба PDF в одной папке.

Сборка через Docker:

```bash
make practice-pdf
```

Результат: `build/test1_practice.pdf`.

Для удаления артефактов сборки:

```bash
make clean
```

### Лекция и семинар №2: три артефакта

Занятие №2 охватывает кодирование графики, звука, текста, целых и вещественных
чисел, машинных команд, маски и сдвиги. Лекция и семинар рассчитаны на **90 минут
каждый**. В семинаре есть шесть обязательных тематических задач с отдельными
решениями, семь заданий для самостоятельной работы и дополнительные разборы.

Для каждой лекции используется схема: **развёрнутая глава пособия + Reveal.js +
PDF тех же слайдов**. Сейчас презентационные комплекты подготовлены для лекций №2, №3 и №4.

```bash
make lecture2          # пособие, HTML-презентация и PDF слайдов
make lecture2-slides   # только HTML и PDF слайдов
```

| Артефакт | Путь |
|---|---|
| Основное пособие с лекцией и семинаром | `build/adaptation_course.pdf` |
| Reveal.js-презентация | `build/slides/lecture02/index.html` |
| PDF презентации | `build/lecture02-slides.pdf` |
| Отчёт проверки вёрстки слайдов | `build/lecture02-check.json` |

Презентация содержит **52 основных слайда (включая источники) и 10 дополнительных**.
Подробная арифметика float идёт после итогов, отмечена «Дополнительно» и не входит
в 90 минут. Занятие №3 углубляет тему вычислений, округления и погрешностей.
Практикум к контрольной тренирует выбранные темы; графика, звук, Unicode и команды
отрабатываются в семинаре №2 основного пособия.

Исходный PPTX служит образцом оформления и тематической основой. Общая тема
`slides/theme/course.css` воспроизводит формат 16:9, тёмный титул с точечным
декором, светлую рамку обычных слайдов, тёмные округлые блоки, бирюзовые акценты
и типографику с Calibri-совместимым Carlito. Содержание презентации находится
в `slides/lecture02/index.html`; заметки преподавателя — в `aside.notes`.

Сборка выполняется в отдельном Docker-образе с Chromium для экспорта в PDF.
Reveal.js 5.2.1, Playwright 1.58.2 и зависимости закреплены lock-файлом;
версии пакетов шрифтов закреплены в `slides/Dockerfile`. Устанавливать Node.js,
браузер или шрифты на хост для сборки не нужно. Первая сборка требует интернета
для Docker и зависимостей; готовая презентация использует только локальные ресурсы.
Для передачи HTML копируйте **весь каталог `build/slides/`**, включая `vendor/`.

Обычный просмотр возможен открытием HTML-файла. Для режима преподавателя
используйте HTTP-сервер; например, при наличии Python:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory build/slides
```

Адрес: `http://127.0.0.1:8000/lecture02/`. Стрелки и пробел переключают слайды,
`Esc` открывает обзор, `S` — заметки преподавателя. На узком экране удобнее
альбомная ориентация. В PDF каждый слайд занимает одну страницу, фрагменты
раскрыты; заметки преподавателя в PDF не включаются.

Сборка проверяет загрузку ресурсов, отсутствие внешних запросов и переполнений
слайдов, наличие заметок, число и формат страниц PDF. Числовые примеры отдельно
проверяются командой `python3 scripts/check-lecture02.py`.

### Вариант `lecture02-original`: структура исходного PPTX

Вторая презентация сохраняет **60 слайдов, их темы и порядок** из исторического
исходника `legacy/sources/Лекция_2_Кодирование_данных_и_команд.pptx`. Слайды сделаны как редактируемый
HTML на той же общей теме, что и `lecture02`: текст, таблицы, формулы и схемы
можно править в исходнике. Формулировки уточнены, предметные ошибки исправлены.
Факультативная арифметика float остаётся на исходном месте — слайды **42–50**.

Это **действующая альтернативная презентация по лекции №2, которая уже была
фактически прочитана**. Она сохраняется в основном репозитории, собирается и
публикуется в CI наряду с основным сценарием лекции.

```bash
make lecture2-original
```

| Артефакт | Путь |
|---|---|
| Исходник | `slides/lecture02-original/index.html` |
| Reveal.js | `build/slides/lecture02-original/index.html` |
| PDF (60 страниц) | `build/lecture02-original.pdf` |
| Отчёт проверки | `build/lecture02-original-check.json` |

Атрибут `data-source-slide` у каждого слайда связывает его с номером слайда PPTX.
Сборка проверяет непрерывную последовательность 1…60. Это вариант по структуре
PPTX; основной `lecture02` остаётся отдельным сценарием на 90 минут.
После запуска HTTP-сервера из инструкции выше адрес нового варианта:
`http://127.0.0.1:8000/lecture02-original/`.

Оба варианта используют один экспортёр. Реестр `slides/presentations.json`
задаёт ожидаемое число слайдов, число основных слайдов и имя PDF.
Аргументы `slides/build.mjs` и `slides/check-artifacts.mjs`:
`[buildDir] [presentationId]`; по умолчанию — `build` и `lecture02`.
Исторический PPTX нужен только для редакторской сверки, а сборка работает с
HTML-исходником.

Полная сборка обоих вариантов и пособия:

```bash
make lecture2 lecture2-original
```

### Лекция №3: арифметика с плавающей точкой и погрешности

Продолжение IEEE 754 из лекции №2: **90 минут**, 38 основных слайдов
и 8 дополнительных. Сначала разбираются выравнивание порядков, GRS,

### Лекция №4: как устроен компьютер и где исполняется программа

Программа занятия задана в `pud_adaptation_course.tex`. Комплект включает
**90 минут, 55 основных и 8 дополнительных слайдов**, развёрнутый текст
в главе 2 и заметки преподавателя. Рассматриваются CPU, RAM, HDD/SSD, GPU/VRAM,
плата и периферия, шины и контроллеры, иерархия памяти, кэш, DMA и прерывания.
Фон-неймановская и гарвардская организация отделены от прав исполнения страниц.

Сквозной пример `a[1] += 5` показывает два потока: машинные инструкции через
L1I и данные через L1D, регистр и АЛУ. Показаны байты кода, состояния массива
и отложенная запись. Примеры используют Linux x86-64 LP64; условные адреса
и упрощения микроархитектуры явно обозначены.

```bash
make lecture4          # пособие + проверки + HTML/PDF, Docker
make lecture4-slides   # HTML и PDF слайдов, Docker
make lecture4-check    # расчёты Python + сборка/запуск C и NASM в Docker
```

Для расчётной проверки нужен Python 3 (только стандартная библиотека).
Демонстрация запускается в контейнере `linux/amd64`; на ARM требуется
поддержка эмуляции amd64 в Docker. Проверяются размеры, порядок байт,
адресные смещения, результат C/NASM, машинные байты и выравнивание структуры.
Она не измеряет кэш-промахи и аппаратные прерывания: на слайдах это модели.

| Артефакт | Путь |
|---|---|
| Текст лекции в пособии | `build/adaptation_course.pdf` |
| Reveal.js | `build/slides/lecture04/index.html` |
| PDF (63 страницы) | `build/lecture04-slides.pdf` |
| Проверка вёрстки | `build/lecture04-check.json` |

Исходники текста: `tex/lectures/lecture04_intro.tex` и
`tex/lectures/lecture04_memory_execution.tex`. Презентация:
`slides/lecture04/index.html`; схемы: `slides/lecture04/assets/`.
Демонстрация: `demos/lecture04/`. Семинар №4 остаётся отдельным материалом.
Для просмотра через HTTP используйте `/lecture04/` после запуска сервера
из инструкции выше. Для передачи копируйте весь `build/slides/`.

### Лекция №4: архитектура и организация компьютера

Сквозной пример — разработка журнала оценок группы на работающей программе:
запуск → вывод одной оценки → таблица из 16 студентов и четырёх работ → ввод
через BIOS-клавиатуру и IRQ1 → средние → сохранение и загрузка. Комплект
содержит **55 основных и 6 дополнительных слайдов**: аппаратное ограничение
сменяется NASM-фрагментом и результатом в QEMU. C присутствует как пояснение
алгоритма, но не исполняется на учебной машине.

Демонстрация загружается в QEMU без гостевой ОС: BIOS читает первый сектор
виртуальной дискеты, загрузчик NASM читает остальную программу и передаёт ей
управление. Процессор остаётся в 16-битном real mode; GRUB и long mode не
требуются. Учебное оборудование: VGA, PS/2, PIC и отдельный IDE-диск с
RAW-образом. В слайдах отдельно объясняются DMA, USB, современный GPU и NVMe,
но они не выдаются за исполняемый код демо. Аппаратный контракт и клавиши
описаны в `demos/lecture04-journal/README.md`.

```bash
make lecture4-journal       # текст пособия, QEMU-проверки, HTML и PDF
make lecture4-journal-check # шесть версий и проверка ввода/диска в QEMU
make lecture4-journal-run   # интерактивно: http://localhost:6080/vnc.html
make lecture4-journal-run STAGE=3 # ввод через BIOS INT 16h
```

Интерактивный экран доступен через noVNC из Docker по локальному адресу;
данные сохраняются в `build/lecture04-journal/grades.img` между запусками.
Для показа в браузере запустите `make lecture4-journal-run` в отдельном
терминале и откройте указанный адрес. В проверках QEMU работает headless.

| Артефакт | Путь |
|---|---|
| Текст лекции в пособии | `build/adaptation_course.pdf` |
| Reveal.js | `build/slides/lecture04-journal/index.html` |
| PDF (61 страница) | `build/lecture04-journal.pdf` |
| Отчёт вёрстки | `build/lecture04-journal-check.json` |

Исходники: `tex/lectures/lecture04_journal.tex`,
`slides/lecture04-journal/index.html` и `demos/lecture04-journal/`.

## GitHub Actions

В репозитории настроен workflow `.github/workflows/build-pdf.yml`.

Он:

- собирает Docker-образ;
- проверяет расчёты и запускает `make lecture2 lecture2-original lecture4 lecture4-journal` (в том числе QEMU-проверки);
- публикует пособие, PDF вариантов лекций №2 и №4 и общий ZIP HTML как artifact;
- при сборке ветки `master` размещает эти материалы в GitHub Pages;
- при публикации GitHub Release прикрепляет пять PDF и общий ZIP HTML-презентаций.

Для регулярных сборок имя artifact содержит номер сборки, дату-время в UTC и короткий SHA коммита:

```text
adaptation-course-master-build-<run_number>-<YYYYMMDD-HHMMSSZ>-<short_sha>
```

PDF внутри artifact называется аналогично:

```text
adaptation_course-master-build-<run_number>-<YYYYMMDD-HHMMSSZ>-<short_sha>.pdf
```

Для GitHub Pages публикуется актуальная версия:

```text
adaptation_course-latest.pdf
```

Для релизов версия берётся из тега релиза, например:

```text
adaptation_course-v1.0.0.pdf
```

Главы подключаются из каталога `tex/chapters/`.

Файлы глав являются фрагментами LaTeX-документа. В них не нужно добавлять:

- `\end{document}`;
- `\tableofcontents`.

## Статус

Материалы находятся в разработке и постепенно дополняются. Для всего курса предполагается дальнейшая редакторская и предметная проверка: нужно уточнять формулировки, выравнивать стиль изложения и дополнительно проверять численные примеры.

Второй раздел активно наполняется материалом: лекция №4 подготовлена как
развёрнутый текст и презентационный комплект; для последующих занятий
зафиксирована структура. Программа раздела определяется ПУД.
