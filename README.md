# Адаптационный курс к дисциплине «Алгоритмы и алгоритмические языки»

Репозиторий содержит методические материалы адаптационного курса для студентов первого курса факультета Программной инженерии НИУ ВШЭ.

Курс предназначен для выравнивания стартовой подготовки вчерашних школьников перед изучением дисциплины «Алгоритмы и алгоритмические языки», в которой используются язык C и ассемблер NASM.

## Содержание курса

Материалы охватывают:

- системы счисления;
- представление целых и вещественных чисел в памяти компьютера;
- базовые понятия архитектуры ЭВМ;
- основы операционных систем;
- Linux как рабочую среду программиста;
- инструменты сборки программ на C и NASM;
- основы Git;
- приложения со справочными материалами.

## Сборка PDF

Локальная сборка выполняется только в Docker-контейнере. Устанавливать TeX Live или другое тяжёлое TeX-окружение в систему не требуется.

Для сборки PDF:

```bash
make pdf
```

Результат появится в каталоге:

```text
build/adaptation_course.pdf
```

Для удаления артефактов сборки:

```bash
make clean
```

## GitHub Actions

В репозитории настроен workflow `.github/workflows/build-pdf.yml`.

Он:

- собирает Docker-образ;
- запускает LaTeX-сборку через `make pdf`;
- публикует PDF как artifact;
- при сборке ветки `master` публикует актуальную версию PDF через GitHub Pages;
- при публикации GitHub Release прикрепляет PDF к релизу.

Для регулярных сборок имя artifact содержит номер сборки, дату-время в UTC и короткий SHA коммита:

```text
adaptation-course-master-build-<run_number>-<YYYYMMDD-HHMMSSZ>-<short_sha>
```

PDF внутри artifact называется аналогично:

```text
adaptation_course-master-build-<run_number>-<YYYYMMDD-HHMMSSZ>-<short_sha>.pdf
```

Для GitHub Pages публикуется актуальная версия:

```text
adaptation_course-latest.pdf
```

Для релизов версия берётся из тега релиза, например:

```text
adaptation_course-v1.0.0.pdf
```

## Основной файл

Главная точка входа для полного документа:

```text
adaptation_course.tex
```

Черновики из `drafts/` не являются целями сборки.

## Требования

Для локальной сборки нужны:

- Docker;
- `make`.

TeX Live на хост-системе не требуется.

## Работа с материалами

Главы подключаются из каталога `tex/chapters/`.

Файлы глав являются фрагментами LaTeX-документа. В них не нужно добавлять:

- `\documentclass`;
- `\usepackage`;
- `\begin{document}`;
- `\end{document}`;
- `\tableofcontents`.

Общие настройки LaTeX находятся в `tex/preamble.tex`.

## Статус

Материалы находятся в разработке и постепенно дополняются. Для всего курса предполагается дальнейшая редакторская и предметная проверка: нужно уточнять формулировки, выравнивать стиль изложения и дополнительно проверять численные примеры.

Второй раздел активно наполняется материалом: сейчас в нём зафиксирована структура тем, обязательные и усложнённые части, а также набор ключевых технологий для изучения.
