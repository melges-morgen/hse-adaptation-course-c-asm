Задание 3

Дана команда:

sort names.txt > sorted.txt 2> errors.log

Объясните, куда попадёт:

  1. обычный вывод программы sort;
  2. сообщения об ошибках;
  3. что произойдет с содержимым файла sorted.txt, если он уже существовал.

Напишите одну команду, которая:

  1. запускает программу check,
  2. сохраняет её обычный вывод в файл report.txt,
  3. при этом сообщения об ошибках по-прежнему выводит на экран, а не в файл.

Отве: ./check > report.txt

Задание 4.

напишите одну команду, которая найдет в файле log.txt все строки со словом ERROR и сохранит только первые 5 таких строк в файл first_errors.txt.

Ответ: grep "ERROR" log.txt | head -5 > first_errors.txt

Задание 5

Вы находитесь в каталоге ~/projects/my_project/src и пытаетесь собрать и запустить программу:

$ gcc main.c -o main

$ main

bash: main: command not found

Компиляция прошла без ошибок, файл main действительно появился в каталоге. Почему возникает ошибка command not found и какая точная команда запустит программу?

Ответ: ./main — команда без ./ ищется в каталогах из PATH, а текущий каталог туда обычно не входит.

Задание 6

Объясните, почему команда ls запускается просто по имени, а свою программу ./my_program нужно запускать с ./. При чём здесь переменная окружения PATH?

Программа my_program лежит в /home/user/tools/. Напишите одну команду, которая позволит запускать my_program просто по имени (без ./ и без полного пути), не копируя файл никуда.

Отввет: export PATH=$PATH:/home/user/tools
