# Демонстрационная лабораторная: сумма двух чисел

Это короткий **учебный образец** того, как зафиксировать ожидание, заметить ошибку, проверить её в GDB и оформить вывод. Задание не заменяет лабораторные семинара №4. Рядом опубликован полностью заполненный пример отчёта: используйте его как ориентир по структуре, а в своих отчётах приводите собственные команды и наблюдения. Понадобятся терминал Linux, GCC, GDB и текстовый редактор. В этой демонстрации ввод не требуется: значения заданы прямо в коде.

## Порядок сдачи демонстрационной работы

1. **На занятии** выполните часть работы, запишите команды, расчёты и наблюдаемый результат и покажите его преподавателю. Это промежуточный показ, а не окончательная сдача.
2. **К следующей лабораторной** завершите работу и подготовьте отчёт: что сделали, как проверяли, что ожидали и что наблюдали. **Отправьте преподавателю отчёт в формате PDF или HTML.** Сохраните исходники и результаты отдельно для демонстрации.
3. **В начале следующей лабораторной** пройдите короткий тест по базовой теории предыдущей работы. Тест обязателен, но его результат не является допуском к устной защите.
4. **Во время следующей лабораторной** индивидуально защитите предыдущую работу: покажите отчёт и работающий результат, объясните свои действия и ответьте на вопросы. Преподаватель сообщит, что нужно исправить.
5. **Последняя лабораторная** выполняется, показывается и защищается на том же занятии. В его начале проходит тест по предпоследней работе; отдельного следующего теста по последней работе не будет.

Для этой демонстрации попробуйте оформить свой небольшой отчёт по той же схеме. Заполненный образец предназначен для изучения оформления, не для сдачи вместо собственной работы.

## 1. Предскажите результат и напишите программу

```sh
mkdir -p ~/aiya/demo-sum
cd ~/aiya/demo-sum
nano sum.c
```

Перепечатайте код в редактор, сохраните через **Ctrl+O**, **Enter**, затем выйдите через **Ctrl+X**:

```c
#include <stdio.h>

int main(void)
{
    int a = 7;
    int b = 5;
    int result = a - b;
    printf("Сумма: %d\n", result);
    return 0;
}
```

**До запуска** запишите в отчёт: задача — вычислить сумму `a + b`; при `a = 7` и `b = 5` ожидается `12`. Намеренная логическая ошибка в исходнике пока не отмечена: ваша цель — обнаружить её по расхождению между ожиданием и наблюдением.

## 2. Соберите и сравните с ожиданием

```sh
gcc -std=c11 -Wall -Wextra -g -O0 sum.c -o sum
./sum
echo $?
```

Ожидайте вывод `Сумма: 2`, затем `0` как код завершения. Сборка без предупреждений означает, что GCC не обнаружил проблем, о которых умеет предупредить при этих флагах; она **не доказывает**, что формула правильная. Нулевой код завершения говорит лишь о том, что программа сама сообщила об успешном окончании. В отчёте сохраните оба наблюдения — `2` и `0` — и сравните первое с предсказанием `12`. `-g` добавляет сведения для отладчика, `-O0` делает сопоставление шагов GDB с исходником проще.

## 3. Исследуйте расхождение в GDB

В обычном терминале выполните `gdb -q ./sum`. После приглашения `(gdb)` вводите команды отладчика по очереди:

```text
break sum.c:7
run
print a
print b
next
print result
quit
```

`break sum.c:7` остановит программу **перед** строкой `int result = a - b;` в приведённом коде (если вставляли строки, номер изменится). `run` начинает исполнение; после остановки `print a` покажет `7`, `print b` — `5`. `next` выполнит строку вычисления, и только тогда `print result` покажет `2`. Числа после знака `$` в ответах GDB — номера результатов команды `print`, а не имена переменных C. `quit` выходит из отладчика. Запишите в отчёт наблюдения и объясните, почему получилась двойка.

## 4. Исправьте код и проверьте снова

Откройте `nano sum.c`, замените `a - b` на **`a + b`**, сохраните файл и снова соберите его той же командой GCC. Повторный запуск `./sum` даст `Сумма: 12`. Запись исходника на диск **не меняет старый исполняемый файл**: без пересборки вы по-прежнему увидите прежний результат.

Для двух дополнительных проверок по очереди измените числа в исходнике, каждый раз пересоберите и запустите программу. Запишите ожидаемый и наблюдаемый результаты:

| `a` | `b` | Ожидаемая сумма |
|---:|---:|---:|
| `0` | `5` | `5` |
| `-3` | `5` | `2` |

После проверки верните в файл `a = 7` и `b = 5` и пересоберите. Сохраните файл `sum.c` отдельно от отчёта для показа. Сравните свой отчёт с заполненным образцом рядом с методичкой: в нём есть цель, команды, ожидания, наблюдения, найденная ошибка, повторная проверка и вывод.
