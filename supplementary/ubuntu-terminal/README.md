# Загрузка Ubuntu и первые шаги в терминале

Эта дополнительная методичка рассчитана на компьютер, где **Ubuntu уже установлена рядом с Windows** и при включении доступен загрузчик GRUB 2. Устанавливать Ubuntu, менять разделы диска или настройки загрузчика здесь не требуется. После входа в Ubuntu вы создадите учебную папку, напишете текстовый файл и научитесь находить, копировать и перемещать файлы. Все примеры выполняйте от имени обычного пользователя.

## Выбор Ubuntu в GRUB 2

1. Сохраните работу в запущенной системе и перезагрузите компьютер. GRUB 2 — это меню выбора операционной системы, которое появляется **до** запуска Ubuntu или Windows.
2. Если меню появилось, стрелками выберите пункт **Ubuntu** (не **Advanced options for Ubuntu** и не **Windows Boot Manager**) и нажмите **Enter**. Названия и оформление могут немного отличаться.
3. Дождитесь экрана входа Ubuntu, выберите свою учётную запись и введите пароль. При наборе пароля символы могут не отображаться — это нормально. После входа дождитесь рабочего стола.

Если меню GRUB 2 не появилось, но сразу загрузилась Ubuntu, переходите к следующему разделу: иногда меню скрыто при автоматическом запуске. Если запустилась Windows либо в меню нет Ubuntu, остановитесь и уточните у преподавателя или администратора, как выбрать установленную систему **на этом компьютере**. Не меняйте разделы диска или параметры загрузчика ради выполнения этой инструкции.

## Открываем терминал

На рабочем столе Ubuntu нажмите **Ctrl+Alt+T**. Откроется окно терминала с приглашением ввести команду. Другой способ: откройте обзор приложений, найдите **Терминал** (*Terminal*) и запустите его. Если сочетание клавиш в вашей конфигурации не сработало, используйте поиск приложений.

**Терминал** показывает введённые команды и их результат. **Командная оболочка** (*shell*, часто Bash) читает команду, например `pwd`, и запускает её. В приглашении могут быть имя пользователя, имя компьютера и знак `$` — **сам знак `$` из примеров вводить не нужно**. Чтобы выполнить набранную команду, нажмите **Enter**. Команда может ничего не напечатать, если выполнилась успешно.

## Где мы находимся: каталоги и пути

Введите по очереди:

```sh
pwd
ls
cd ~
pwd
```

`pwd` показывает **текущий каталог** (*working directory*), а `ls` — его содержимое. `cd` меняет текущий каталог. Знак `~` означает ваш **домашний каталог**; результат `pwd` после `cd ~` будет похож на `/home/ваше_имя`. Это пример, а не одинаковый для всех путь.

В Linux корень дерева каталогов обозначается `/`. Путь `/home/ваше_имя` начинается с `/` и называется **абсолютным**. Имя `notes.txt` задаёт путь от текущего каталога — это **относительный** путь. `.` означает текущий каталог, `..` — родительский. Регистр букв важен: `Notes.txt` и `notes.txt` — разные имена.

## Создаём учебный каталог и файл

Начиная из домашнего каталога, выполните:

```sh
mkdir terminal-practice
cd terminal-practice
pwd
touch notes.txt
ls
```

`mkdir` создал каталог; `cd` перешёл в него. `touch` создал пустой файл `notes.txt` (если файл уже существует, команда обновит время его изменения). `ls` теперь должен показать `notes.txt`. Если `mkdir` сообщает `File exists`, учебная папка уже существует: перейдите в неё командой `cd terminal-practice` и проверьте содержимое командой `ls`, прежде чем продолжать.

Сохраните текст в файле через редактор **nano**:

```sh
nano notes.txt
```

Введите в редакторе две строки, например:

```text
Изучаю терминал Ubuntu.
Мой первый текстовый файл.
```

**Сохраните файл в nano**: нажмите **Ctrl+O** (буква O), затем **Enter** для подтверждения имени. Нажмите **Ctrl+X**, чтобы выйти. Подсказки внизу nano используют символ `^` для клавиши Ctrl: `^O` означает Ctrl+O. Если при выходе редактор спрашивает о сохранении несохранённых изменений, подтвердите сохранение и имя файла.

Убедитесь, что файл содержит ваш текст:

```sh
cat notes.txt
```

`cat` выводит содержимое небольшого текстового файла в терминал. Для длинного файла удобнее `less notes.txt`: прокрутка — стрелками, выход — клавишей **q**.

## Копируем, переименовываем и удаляем

Оставайтесь в `terminal-practice`. Команды ниже работают только с файлами учебного примера:

```sh
cp notes.txt notes-copy.txt
ls
mv notes-copy.txt draft.txt
mkdir archive
mv draft.txt archive/
ls archive
rm archive/draft.txt
rmdir archive
ls
```

`cp` делает копию, `mv` переименовывает файл или переносит его в каталог, `rm` удаляет файл, а `rmdir` удаляет **пустой** каталог. В конце `notes.txt` остаётся на месте. Перед `rm` проверьте путь через `ls`: обычно удаление из терминала не перемещает файл в корзину. Не применяйте эти команды к незнакомым каталогам.

Из учебного каталога команда `cd ..` вернёт вас на уровень выше — домой. Команда `cd ~` вернёт домой из любого каталога. Проверяйте результат через `pwd`.

## Короткая памятка и помощь

| Команда | Что делает |
| --- | --- |
| `pwd`, `ls`, `ls -a` | Показать текущий каталог, его содержимое и скрытые имена. |
| `cd ..`, `cd ~` | Перейти на уровень выше или домой. |
| `mkdir`, `touch`, `nano` | Создать каталог, пустой файл или отредактировать текст. |
| `cat`, `less` | Вывести текст или просмотреть его постранично. |
| `cp`, `mv`, `rm`, `rmdir` | Копировать, переместить, удалить файл или пустой каталог. |
| `grep -n 'Ubuntu' notes.txt` | Найти строки со словом `Ubuntu` и показать их номера. |
| `find . -name '*.txt'` | Найти файлы с именем, заканчивающимся на `.txt`, начиная с текущего каталога. |
| `wc -l notes.txt` | Посчитать строки в файле. |

В примере с `find` кавычки вокруг `*.txt` нужны, чтобы образец имени обрабатывала команда `find`, а не оболочка заранее. Для справки по команде попробуйте `ls --help` или `man ls`; из справки `man` выходят клавишей **q**. Команды вводите без обратных кавычек — здесь они лишь выделяют текст команды.

## Самостоятельная практика

Из домашнего каталога создайте каталог `my-work`, войдите в него, создайте файл `plan.txt` и запишите в нём две собственные строки через `nano`. Проверьте содержимое командой `cat`, создайте копию `plan-copy.txt`, переименуйте её в `backup.txt`, посмотрите список файлов и удалите **только** `backup.txt`. В результате в `my-work` должен остаться `plan.txt` с вашим текстом. Для проверки используйте `pwd`, `ls` и `cat plan.txt`.

Если команда отвечает `No such file or directory`, сначала проверьте `pwd` и `ls`: возможно, вы находитесь не в той папке либо ошиблись в имени (включая регистр). `cd` не создаёт каталог: перед переходом каталог должен существовать. Если команда отвечает `command not found`, проверьте написание команды, пробелы и раскладку клавиатуры; не повторяйте её с `sudo` наугад. Если завис просмотр в `less` или `man`, нажмите **q**; если нужно прервать выполняющуюся команду, нажмите **Ctrl+C**.
