# Правила архива

Файлы под `legacy/` сохранены для исторической сверки. Они не определяют
актуальную программу, текст пособия или состав презентаций и не должны
подключаться к активным целям сборки.

Источники текущих требований перечислены в корневом `AGENTS.md`. Для раздела 2
программы это `pud_adaptation_course.tex`; для основного пособия —
`adaptation_course.tex` и файлы под `tex/`.
