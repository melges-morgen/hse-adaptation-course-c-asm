# Архив исторических материалов

Каталог содержит материалы, которые сохранены для исторической сверки, но не
являются источниками текущего содержания курса и не участвуют в сборке.

Исходники прежней x86-64-версии журнала лекции №4 находятся в
`demos/lecture04-journal-x86_64/`, её HTML в
`slides/lecture04-journal-x86_64/`, а текст — в
`tex/lectures/lecture04_journal_x86_64.tex`. Действующий вариант:
`demos/lecture04-journal/`, `slides/lecture04-journal/` и
`tex/lectures/lecture04_journal.tex` (16-битный NASM/BIOS).

| Архивный материал | Причина переноса | Актуальная замена |
|---|---|---|
| `Программа курса.md` | Старый общий план расходится с актуальной программой раздела 2 | `pud_adaptation_course.tex` для раздела 2; `tex/chapters/` для текста пособия |
| `drafts/adaptation_course_combined_draft.tex` | Сводный черновик | `adaptation_course.tex` и подключённые файлы под `tex/` |
| `tex/practice/test1/theory.tex` | Старая отдельная памятка, не подключённая к актуальному практикуму | Теория в основном пособии и файлы под `tex/practice/test1/` |
| `sources/Лекция_2_Кодирование_данных_и_команд.pptx` | Исторический исходник уже переработанной презентации | `slides/lecture02-original/index.html` |

Не подключайте файлы из этого каталога к актуальным LaTeX- и slide-сборкам без
отдельного согласования. Если архивный материал используется для проверки
истории, это должно быть явно указано в плане или комментарии к изменению.
