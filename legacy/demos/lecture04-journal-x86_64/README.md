# Историческая 64-битная демонстрация журнала

Исходный вариант использовал GRUB Multiboot2, переход в long mode, C и
NASM. Сохранён для сравнения решений. Действующая 16-битная версия находится
в `demos/lecture04-journal/` и запускается через цели `lecture4-journal-*`.
Архив не является целью сборки и не определяет учебное содержание.
