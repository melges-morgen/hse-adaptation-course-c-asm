# Именной тест по лекции и лабораторной работе № 4

Источник ФИО и подгрупп — локальный `groups/students.csv`. Расписание пяти
дней хранится в `assessments/lecture04/days.json`, вопросы — в
`scripts/lecture04_quiz/bank.py`. Для каждого студента делаются два бланка:
базовая лабораторная на C и усложнённая на NASM/BIOS/QEMU. Из двух бланков
студенту выдаётся только соответствующий выполненной работе.

Из корня репозитория выполните:

```sh
python3 -m unittest discover -s tests -p test_lecture04_quiz.py -v
python3 scripts/generate-lecture04-quiz.py \
  --seed quiz4-2026-v4 \
  --output dist/lecture04-quiz/quiz4-2026-v4-5min
```

Команда собирает PDF в Docker. В `print/BPI264-1.pdf` лежит весь комплект
подгруппы БПИ264-1 в порядке студенческих ID: по две страницы на каждый из
двух лабораторных вариантов студента. Аналогично создаются ещё 19 PDF.
На студенческих бланках указано время 5 минут; день в шапке не печатается,
но остаётся частью кода бланка.
Отдельные `keys/BPI264-1.pdf` и `manifest.json` содержат ответы в напечатанном
порядке; они предназначены преподавателю, не студентам. Весь выпуск находится
в игнорируемом Git каталоге `dist/`; личные данные и ответы не включаются
в студенческие архивы.

Для нового выпуска укажите новый `--seed` и **пустой** `--output`. Один и тот
же seed вместе с тем же списком, расписанием и банком даёт те же задания и
ключи независимо от порядка строк CSV. `--tex-only` создаёт только TEX и
манифест, не требуя Docker.

Старые бланки `quiz-c.tex` и `quiz-journal.tex` — отдельный готовый тест без
имён; команда `make lecture4-quiz` по-прежнему собирает их вместе с кратким
ключом `teacher-key.tex`.
