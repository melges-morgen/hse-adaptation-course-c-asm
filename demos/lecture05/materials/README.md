# Материалы к лекции №5

Запускайте команды из корня распакованного набора материалов.

- `process_demo.c` — исходный текст короткой программы для наблюдения
  аргументов, переменной окружения, стандартного ввода, вывода и кода
  завершения.

Программа компилируется в Linux с установленным GCC:

```sh
gcc -std=c11 -Wall -Wextra -Werror process_demo.c -o process-demo
printf 'первая строка\nвторая строка\n' > input.txt
COURSE_MESSAGE='Привет' ./process-demo первый второй < input.txt > output.txt 2> errors.txt
echo $?
```

Для проверки кода завершения попробуйте `./process-demo --status=7`, затем
сразу выполните `echo $?`. Значение 7 выбрано специально как демонстрационное;
в реальных программах смысл ненулевого статуса задаётся самой программой.
