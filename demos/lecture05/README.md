# Проверка демонстрации лекции №5

Из корня репозитория выполните:

```sh
make lecture5-check
```

Команда собирает контейнер Debian с GCC и запускает сценарий проверки. Исходник
компилируется с `-Wall -Wextra -Werror`, затем проверяются аргументы,
переменная окружения, копирование стандартного ввода в вывод, отдельное
сообщение в `stderr` и коды завершения. Исполняемый файл остаётся во временном
каталоге контейнера и не попадает в материалы студентов.
