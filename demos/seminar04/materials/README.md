# Файлы для лабораторной работы №4

Эта папка — готовый комплект для студента. Файлы лежат рядом друг с другом:
для занятий не нужно восстанавливать дерево исходников курса. Пошаговая
методичка семинара выдаётся отдельно в HTML и PDF.

| Файл | Для чего нужен |
|---|---|
| `hello.asm` | Первый загрузочный сектор: выводит `HELLO BIOS`. |
| `boot16.asm` | Общий загрузчик: BIOS запускает его, а он читает `journal.asm` с дискеты. |
| `journal.asm` | Полная шестая версия журнала оценок: редактируйте свою копию, собирайте NASM и запускайте в QEMU. |
| `memory.c` | Пример под Linux x86-64: размеры типов, байты, адреса массива и переход к теме процессов. |
| `memory.gdb` | Справочный список команд GDB для изучения `memory.c`; на занятии вводите команды вручную. |

Откройте полную методичку и выполняйте команды **из этой папки**. Рабочие
копии создавайте в `work/`: они не заменят исходные файлы из архива.
`hello.bin` и `journal.bin` — машинный код для BIOS, их не запускают через
`./имя_файла` как программу Linux.
