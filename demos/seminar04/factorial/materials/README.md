# Семинар №4 · вариант 1 (базовый)

`input.txt` содержит число 5 для опыта с перенаправлением и GDB. Полная методичка
находится рядом с папкой `materials/` в HTML или PDF; код `factorial.c` студент
создаёт вручную по тексту методички. После распаковки архива в рабочем каталоге
можно использовать `input.txt` командой `./factorial < input.txt` после сборки
программы. Архив не содержит готового решения или файлов преподавателя.
