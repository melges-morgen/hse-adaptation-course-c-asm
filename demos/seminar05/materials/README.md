# Лабораторная работа №5: Git и процессы

Поместите выданные файлы в отдельный рабочий каталог, например
`~/aiya/lab05`, и перейдите в него. Создавайте Git-репозиторий именно там,
не внутри исходного репозитория курса.

| Файл | Назначение |
| --- | --- |
| `README.md` | Состав комплекта и стартовые команды. |
| `status_demo.c` | Программа для наблюдения кода возврата и stderr. |
| `isolation_demo.c` | Родитель и потомок: PID, адреса и разные значения переменной. |

Сначала выполните **часть I про Git** из методички: начальный коммит,
ветка, слияние и обмен через соседний bare-репозиторий. Только после этого
собирайте программы для части II:

```sh
gcc -std=c11 -Wall -Wextra -O0 status_demo.c -o status_demo
gcc -std=c11 -Wall -Wextra -O0 isolation_demo.c -o isolation_demo
./status_demo --code=7
echo $?
./isolation_demo
echo $?
```

Программы собираются из исходников в рабочем каталоге. Команда
`./isolation_demo --observe` даёт около восьми секунд для просмотра PID
дочернего процесса через `ps` во втором терминале. Полная инструкция,
контрольные вопросы и порядок сдачи находятся в методичке семинара №5.
