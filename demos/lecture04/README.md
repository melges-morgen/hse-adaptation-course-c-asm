# Демонстрация лекции №4

Запуск из корня репозитория: `make lecture4-check`.
Компиляция и выполнение происходят в Docker **linux/amd64**. На ARM-хосте
потребуется поддержка эмуляции amd64 в Docker. На хост не устанавливаются
GCC или NASM; первая сборка контейнера требует доступа к Debian-репозиториям.

- `memory.c`: размеры LP64, байты little-endian, адреса массива, динамический
  блок, выравнивание структуры, проверка результата и машинных байтов.
- `add_middle.asm`: вызываемая из C функция; RBX сохраняется по System V ABI.
  Метки `trace_start` и `trace_end` ограничивают три инструкции со слайдов.
- `Dockerfile`: компилятор, ассемблер, сборка и запуск с предупреждениями как
  ошибками. Временные объектный и исполняемый файлы остаются в `/tmp` контейнера.

Результат: `10 20 30` → `10 25 30`. Реальные адреса печатаются для наблюдения
и могут меняться между запусками; `0x1000` и `0x400000` в лекции условные.
Демонстрация проверяет архитектурный результат, но не измеряет кэш-промахи,
DMA или аппаратные прерывания. Их диаграммы в лекции являются моделями.
