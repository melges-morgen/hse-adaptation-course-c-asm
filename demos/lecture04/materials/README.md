# Исходники к лекции №4

Распакуйте архив и работайте из этой папки: все файлы лежат рядом.
Код C здесь работает в Linux x86-64, а шестнадцатибитный
журнал запускается через BIOS в QEMU — это разные программы.

| Файл | Назначение |
|---|---|
| `memory.c` | Пример адресов, байтов, структуры и массива C под Linux x86-64. |
| `add_middle.asm` | Вызываемая из C функция NASM, прибавляющая 5 к среднему элементу. |
| `Dockerfile` | Самостоятельная сборка и запуск пары `memory.c` + `add_middle.asm` в Docker. |
| `boot16.asm` | Общий загрузочный сектор для всех шести версий журнала. |
| `journal-stage1.asm` | Вывод одной оценки через сервисы BIOS. |
| `journal-stage2.asm` | Таблица оценок и прямой вывод в VGA. |
| `journal-stage3.asm` | Ввод и исправление оценок через клавиатурный сервис BIOS. |
| `journal-stage4.asm` | Собственный обработчик IRQ клавиатуры. |
| `journal-stage5.asm` | Подсчёт статистики по оценкам. |
| `journal-stage6.asm` | Сохранение и восстановление оценок на отдельном диске. |

Для демонстрации C/NASM на компьютере с Docker:

```sh
docker build --platform linux/amd64 -t lecture04-demo .
docker run --rm --platform linux/amd64 lecture04-demo
```

Чтобы сравнить механизмы в журнале, используйте, например,
`diff -u journal-stage3.asm journal-stage4.asm`. Для работы с определённой
версией NASM берите её собственный файл и общий `boot16.asm`. В отличие
от `memory.c`, эти исходники собираются в плоские 16-битные бинарные файлы
для образа дискеты и QEMU, а не в исполняемый файл Linux.
